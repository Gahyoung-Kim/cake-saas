앱 버전 복잡도 예상
PWA 방식 (현재 웹앱 → 설치 가능 앱)

*현재 웹앱 코드 그대로 사용
+ manifest.json 추가
+ Service Worker 추가
= 홈화면 설치 가능, 오프라인 대응, 푸시알림
예상 작업량: 1~2일

앱스토어 배포는 불가, 브라우저 내 설치형

*Capacitor 방식 (현재 웹앱 → 네이티브 앱 래핑)
현재 웹앱 코드 그대로 사용
+ Capacitor 설치 및 설정
+ iOS/Android 프로젝트 생성
= 앱스토어 배포 가능
예상 작업량: 3~5일

카메라, 푸시알림 등 네이티브 기능 추가 가능

React Native 새로 짜는 것보다 훨씬 빠름

*React Native 방식 (완전 새로 작성)
UI 전부 재작성
API 연동 새로 작성
= 진짜 네이티브 퍼포먼스
예상 작업량: 3~4주

현재 코드 재사용 거의 불가

추천 경로

지금: 세세한 수정 + 결제 연동 + 테스트
       ↓
1단계 앱: Capacitor로 현재 웹앱을 네이티브 앱으로 래핑
          → 앱스토어 배포, 코드 재작업 최소화
       ↓
필요시: React Native 별도 앱 (훨씬 나중에)
결론: 앱 버전은 복잡하지 않습니다. Capacitor 기준으로 현재 코드 80%를 그대로 쓰면서 앱스토어 배포까지 가능합니다.
