※ 도커로 실행할때

1단계 — Docker Desktop 실행 (필수)
Docker Desktop이 꺼져 있으면 docker compose 자체가 동작 안 합니다.
트레이 아이콘에서 Docker고래 아이콘이 돌아가고 있는지 확인.

2단계 — 빌드 & 실행
# C:\kkh\cake_saas> 에서
docker compose up --build

3단계 — DB 마이그레이션 (최초 1회만)
컨테이너가 다 뜨면 별도 터미널에서:
docker exec -w /app caker-backend alembic -c backend/alembic.ini upgrade head

.env 주의사항
현재 .env의 DATABASE_URL이 로컬 MySQL을 가리키고 있습니다:

DATABASE_URL=mysql+pymysql://root:1234@localhost:3306/cakesaas  ← 로컬용
Docker 실행 시에는 docker-compose.yml이 이 값을 자동으로 덮어씁니다 (Docker MySQL로). 그래서 .env는 건드릴 필요 없습니다.


이후 실행 (두 번째부터)

# 코드 변경 없을 때 (빠름)
docker compose up

# 코드/패키지 변경했을 때
docker compose up --build

Docker Desktop 켜기 → docker compose up --build → 최초 1회 마이그레이션
